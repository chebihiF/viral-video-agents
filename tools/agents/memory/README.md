# Mémoire des agents (modèle)

Ce dossier ne contient que le **modèle** d'un fait. Les faits réels vivent dans la mémoire
locale de chaque agent, **hors du dépôt**, et ne sont jamais committés.

- Conventions : `docs/agents-memory.md` ; décision : `docs/adr/ADR-003-memoire-agents.md`.
- Un fait = un fichier ≤ 10 lignes, d'après `modele-fait.md`.
- Expiration 90 jours par défaut, puis revue (prolonger ou supprimer).
- Interdit : secrets, prompts, dictées, données d'enfant, contenu de conversation.
- Décision d'architecture : ADR. État de ticket : issue GitHub.
